About the Event

Event Overview

The SEU Tech Event is an annual technology showcase organised by Southeast University to bring together students, faculty members, and industry professionals interested in modern computing. The event includes workshops, project exhibitions, and competitive programming sessions.

The main goal of this event is to encourage students to apply classroom knowledge to real-world projects and to build stronger connections with the local IT industry.

Event Venue

Auditorium and Computer Lab Building, Southeast University, Dhaka.

Topics and Participation Details

Participants can join sessions covering the following areas. Registration is open to all students who want to sharpen their practical skills before entering the job market.

Core Topics Covered

  • Web Development and HTML/CSS Fundamentals
  • Database Systems and Data Handling
  • Machine Learning and AI Applications
